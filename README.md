# Atividades de Programação Web

Projeto com atividades desenvolvidas em HTML, CSS, JavaScript e PHP.

## GitHub Pages

A página inicial está em `index.html`, permitindo publicar a parte estática do projeto pelo GitHub Pages.

> Observação: o GitHub Pages não executa PHP. Os arquivos da Atividade 10 permanecem no repositório, mas precisam de um servidor com suporte a PHP para serem executados.
